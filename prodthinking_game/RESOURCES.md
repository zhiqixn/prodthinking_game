# Product Thinking Resources

## Knowledge

- [IDG: Product Thinking pathway (landing page)](https://www.idg.gov.sg/product-thinking/)
  The course overview: three learning objectives (4Cs, outputs vs outcomes, Five Whys) and links to all seven modules. Use for: the overall map and sequence.
- [IDG Module 1: Understanding the Problem](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking1/)
  Why to start from problems, not technology. Names the three principles (focus on the problem, chase outcomes, integrate policy/ops/tech) and includes a video. Use for: Lesson 1, the foundation.
- [IDG: Start With The Whys](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking2/)
  Root-cause thinking with the Five Whys. Module 1 links here as the next guide. Use for: moving from symptom to cause.
- [IDG: Craft a Clear Problem Statement](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking3/)
  The 4Cs Framework (Clarity, Consequence, Cause, Confirmation) for one sharp, data-backed problem statement. Use for: writing problem statements.
- [IDG Module 4: Metrics](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking4/)
  Measures that reflect outcomes rather than activity. Use for: outputs vs outcomes, success metrics.
- [IDG Module 5: Assumptions and Risks](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking5/)
  Surfacing and testing assumptions early. Use for: risk and validation lessons.
- [IDG Module 6: A Good Customer Experience](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking6/)
  What it feels like to use what you build. Use for: customer-experience lessons.
- [IDG Module 7: Key Takeaways](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking7/)
  The three mindset shifts and the toolkit (5 Whys, 4Cs, SMART + VCR, Staged Delivery, 11 Star framework). Use for: review and spaced retrieval.
- [Craft (public officers only)](https://craft.cio.sandbox.gov.sg/)
  Product-management resource collection linked from the IDG page. Not accessible publicly; use only if the learner has access.

## Wisdom (Communities)

- [IDG Community](https://www.idg.gov.sg/community/)
  IDG's community hub for public-sector digital practitioners. Not yet reviewed in detail. Use for: finding practitioners to test ideas with.

## Gaps

- Module 1 names its three principles only in a graphic, without definitions. Definitions must come from later modules (Metrics for "chase outcomes").
- The landing page's module numbering and URLs disagree: "Craft a Clear Problem Statement" (Module 2) links to `productthinking3`, and "Start With The Whys" (Module 3) links to `productthinking2`. Module 1's "next guide" is the Whys page, so this course follows that order.
- No source yet for how "SMART + VCR", "Staged Delivery" and the "11 Star framework" work. Read the relevant module pages before teaching them.
